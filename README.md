# Portfolio - Sergiu Neagu

Personal portfolio. I'm a full-stack developer based in Antwerp, studying IT at AP Hogeschool. I build websites and applications for local businesses and schools.

**Live:** [neagu-sergiu-portfolio.vercel.app](https://neagu-sergiu-portfolio.vercel.app/)

## What's on it

- Selected work: Neagu Group (live client site), GoSmartLib (school library platform, with demo video) and MailClean (own product)
- Six more projects, each linked to its GitHub repository
- Skills, education and experience
- Website pricing with a selector that updates the quote
- Three languages (EN / NL / FR), remembered per visitor
- Light and dark mode, following the system setting by default

## Tech stack

One static page: HTML, CSS and vanilla JavaScript. No framework, no build step, no dependencies.

The projects shown on it use Java, Spring Boot, Angular, TypeScript, Flutter, React Native, Docker and more.

## Run locally

```bash
git clone https://github.com/sergiuNE/Portfolio.git
cd Portfolio
python -m http.server 8000
```

Then open http://localhost:8000. Opening `index.html` directly in a browser also works.
